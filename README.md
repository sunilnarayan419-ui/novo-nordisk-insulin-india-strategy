# Novo Nordisk India Insulin Strategy — Case Study Repository

An independent, publicly-sourced strategy consulting case study addressing: *How should Novo Nordisk optimize its insulin portfolio, pricing/access strategy, and market approach in India over the next 3–5 years to increase appropriate insulin adoption and patient access while protecting sustainable revenue, margins, and competitive position?*

**⚠️ See `DISCLAIMER.md` — this is an independent educational case study, not a Novo Nordisk-commissioned or Novo Nordisk-affiliated document, and uses no confidential or non-public company information.**

## Start Here
1. `00_PROJECT_CHARTER/problem-statement.md` — the full problem brief
2. `17_CONSULTING_DELIVERABLES/executive-summary/` — the one-page synthesis
3. `11_STRATEGIC_OPTIONS/recommended-strategy.md` — the final recommendation
4. `10_FINANCIAL_MODEL/README.md` — the quantitative model and headline results

## Structure
See `project_structure.md` for the full folder map. The repository follows a 20-section strategy-consulting structure, from problem framing (00) through market/competitive/health-economics/supply-chain analysis (02–09), a quantitative decision model (10), strategic options and recommendation (11), implementation and risk (12–13), supporting data/analytics/exhibits (14–16), final deliverables and QA (17–19), and career-portfolio materials (20).
